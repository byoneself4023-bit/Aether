## 🌐 Aether 시나리오 결정 — 명확히 박힘

```
[현재 시나리오 — 시나리오 A: 기술 데모]
  목적: 기술 데모 + 시니어 시그널
  사용자: 0명 (포트폴리오 / 면접용)
  방향성: AI Agent 시스템 + 시니어 패턴 정착
  완성 조건: Top 10 종료 + 면접 답변 가능
```

### 결정 사유

1. **포트폴리오 출발점.** Aether는 시작 시점부터 *"기술 데모"* 목적
2. **도메인 검증 X.** 너 본인이 포트폴리오 분석 도구 실 사용자 X
3. **시니어 시그널 효과.** LangGraph / ReAct / MCP / RAG / JWT / Pydantic 풀 스택 = 면접 어필 강
4. **시나리오 혼동 방지.** *"포트폴리오 + 실서비스"* 둘 다 잡으면 어중간

### 시나리오 전환 트리거

만약 시나리오 B (실서비스) / C (SaaS) 진입을 고려하게 되면:

1. **도메인 질문:** *"한국 개인 투자자가 진짜 겪는 문제 Top 5는?"*
2. **사용자 질문:** *"나는 이 서비스를 실제로 쓸 건가? 안 쓴다면 누가 쓸 건가? 5명 인터뷰해봤나?"*
3. **PMF 질문:** *"사용자가 10불 내고 쓸 가치 있나? 비즈니스 모델 + 수익화 경로?"*

→ **답 안 되면 시나리오 A로 끝내고 별도 프로젝트로 분리.**

## 🎯 면접 답변 (시니어 시그널)

면접관 *"Aether가 뭔가요?"* 첫 질문 시:

> *"Aether는 AI Agent 시스템 학습 + 시니어 패턴 정착이 목적이었어요.*
> *LangGraph / ReAct / MCP / RAG / JWT / Pydantic 풀 스택을 실제로 박아본 사례입니다.*
> *실리콘밸리 랄프톤 우승자 발언처럼 'AI에게 어떻게 해야 하는지 연구하라고 시키는' 패턴을 정착시켰고,*
> *작업 중 발생한 18건 누적 문제를 시스템화해서 같은 실수 반복도 차단했어요.*
> *실서비스 진입은 별도 프로젝트로 도메인 검증부터 시작할 거예요."*

→ *"기술 데모 vs 실서비스 명확히 분리"* + *"시대 트렌드 반영"* = 시니어 시그널.
