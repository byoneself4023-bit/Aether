- **상태**: Accepted (Deferred)

- **결정 근거**: SCENARIO.md (시나리오 A 본질) + PRINCIPLES.md 패턴 6 (미적용 결정 = 시그널) + ADR 0010 / 0011 / 0014 보류 결정 패턴 일관성

## 컨텍스트

CL-1 (PR #38) 머지 후 자료 인덱스 정착. ADR 0024에 영구 보류 영역 3건 명시 — 그 중 코드 정리 (CL-2) / 의존성 정리 (CL-3) 영역 결정 추적 본문이 본 ADR.

Aether 시나리오 = A (사용자 0명 / 기술 데모 + 면접 자료용 / SCENARIO.md §결정 본문). 시나리오 A 본질 X 영역 진입 시 비용 ↑ vs 시그널 ↓ 사례 누적 — ADR 0010 (T-3 Multi-Agent) / 0011 (D-1 본질 X 4건) / 0014 (D-9 RAG 정제) 보류 결정 패턴 일관성.

CL-2 / CL-3 본질 진단:
- 코드 cleanup (사용처 0건 코드 제거 / dead code 정리) = 시나리오 A 본질 X (사용자 0명 / 운영 비용 X)
- 의존성 cleanup (requirements.txt / package.json 사용처 0건 의존성 제거) = 회귀 위험 ↑ vs 정리 가치 ↓
- 진입 의무 시점 = 시나리오 B (production / 사용자 5+ / PMF 검증) — 도메인 검증 후 cleanup 의무 정착

본 카드 = 영구 보류 결정 추적 (자료 영역만 / 코드 0 변경) + 시나리오 B 진입 트리거 명시.

## 결정 (5 분기 추적)

### 분기 1: 영구 보류 vs 시점 한정 보류 — **A 채택** (영구 보류)

옵션 A (선택) = 영구 보류 / 시나리오 B 진입 시점에 검토 / ADR 0010 / 0011 / 0014 패턴 일관성. 시나리오 일관성 시그널 정착.
옵션 B (시점 한정 보류) = Aether 종료 후 즉시 검토 / 시그널 약함 / 시나리오 A 본질 X 영역 진입 위험.

### 분기 2: CL-2 / CL-3 보류 영역 — **A 채택** (동시 보류 / ADR 1건 통합)

옵션 A (선택) = 동시 보류 / 시나리오 A 본질 X 동일 사유 / ADR 1건 통합 (영역 한정).
옵션 B (분리 보류) = ADR 2건 / 영역 ↑ / 가치 X (동일 사유 / 동일 트리거).

### 분기 3: 진입 트리거 — **A 채택** (시나리오 B 진입 시점)

옵션 A (선택) = 시나리오 B 진입 시점 (도메인 검증 + 사용자 5+ 인터뷰 + PMF 10불 검증 / SCENARIO.md §결정 본문 인용).
옵션 B (production 진입 / 시나리오 C) = 너무 늦음 / 시나리오 B 진입 시점에 cleanup 의무 정착.
옵션 C (시점 명시 X) = 시그널 약함 / 보류 추적 어려움 / PRINCIPLES 패턴 6 위반.

### 분기 4: 자료 갱신 영역 — **B 채택** (4 자료 동시 갱신)

옵션 A (ADR 0025만) = 단순 / 자료 일관성 X / 인덱스 영역 정합성 ↓.
옵션 B (선택) = ADR 0025 + adr/README + docs/README + AGENTS §7 / 자료 일관성 정착 / D-4 패턴 일관성.

### 분기 5: 카드 명명 — **B 채택** (CL-D)

옵션 A (CL-2/3-DEFER) = 영역 명시 / 자연스러움 X.
옵션 B (선택) = CL-D (Cleanup Defer) / 단순 / 카드 ID 추적 ↑.
옵션 C (ADR 0025 단독 / 카드 ID X) = 추적 어려움 / 카드 누적 영역 영향 X.

## Decision

1. **CL-2 (코드 cleanup) 영구 보류** — 사용처 0건 코드 제거 / dead code 정리 영역. 시나리오 A 본질 X.
2. **CL-3 (의존성 cleanup) 영구 보류** — requirements.txt / package.json 사용처 0건 의존성 제거 영역. 시나리오 A 본질 X.
3. **시나리오 B 진입 시점 트리거** — 도메인 검증 + 사용자 5+ 인터뷰 + PMF 10불 검증.
4. **자료 4건 동시 갱신** — ADR 0025 + docs/adr/README.md + docs/README.md + AGENTS.md §7.
5. **양면 정책 15 ADR 정립** — 0011-0025 / 정착 7 + 보류 4 + 메타 4.

---

## 시나리오 B 진입 트리거 (3 조건)

SCENARIO.md §결정 본문 인용 — 시나리오 A → B 전환 3 질문이 모두 충족 시 cleanup 의무 진입:

| # | 조건 | 본질 |
|---|------|------|
| 1 | 도메인 검증 | Top 5 문제 정착 (도메인 깊이 + 본질 진단) |
| 2 | 사용자 5+ 인터뷰 진행 | 실 사용자 5명 이상 인터뷰 + PMF 시그널 정착 |
| 3 | PMF 10불 가치 정착 | "사용자가 10불 내고 쓸 가치 있나?" 답 정착 + 비즈니스 모델 + 수익화 경로 |

**3 조건 모두 충족 시점에 CL-2 / CL-3 진입 의무**. 부분 충족 = 진입 X (시나리오 A 본질 일관성 보존).

## 영향

### 시그널 강화 (+)

- **양면 정책 15 ADR 정립**: 0011-**0025** = 시니어 시그널 누적
- **PRINCIPLES 패턴 6 직접 사례**: "미적용 결정 = 명시한 결정만큼 강한 시그널" / T-3 보류 + Houseman 패턴 동일
- **시나리오 일관성 시그널**: 시나리오 A 본질 X 영역 진입 X / B/C 침범 회피 (SCENARIO.md §결정 본문)
- **6개월 후 본인 답 가능**: 시나리오 B 진입 트리거 본문 명시 (PRINCIPLES 원칙 5)
- **ADR 0010 / 0011 / 0014 패턴 일관성**: 보류 결정 양면 정책 4건 정착

### 트레이드오프 (−)

- 시나리오 A 종료 시점에 코드 cleanup X / 의존성 cleanup X = 코드 영역 dead code 잔존 가능
- 시나리오 B 진입 시점에 cleanup 비용 ↑ (누적 dead code / 의존성 영역)
- 다만 본질 진단: 시나리오 A 본질 X 영역에서 cleanup 가치 X / 시나리오 B 진입 시점 cleanup 의무 정착이 본질 적합
