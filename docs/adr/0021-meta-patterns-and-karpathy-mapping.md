## Decision

1. **PRINCIPLES.md §8/§9/§10** 추가 (귀납 / 본인 영역)
   - §8: 신규 endpoint 분리 = 점진 전환 본능 (D-5 / D-6)
   - §9: Auto Research 본능 = 인간 결정 최소화 (D-7)
   - §10: G1 본질 트리거 발견 시 즉시 정정 본능 (T-6b)
2. **KARPATHY_MAPPING.md** 신규 (연역 / 카파시 영역, ~400 LOC)
   - §1 8 본능 정의 + 영상 시간대 (검증 의무 단서)
   - §2 매칭 점수 진화 (76 → 87점) + 진화 사유
   - §3 8 본능 × 14 카드 매핑 표
   - §4 미적용 영역 7건 (시나리오 B 트리거)
   - §5 본인 영역 진화 사례 (META_REVIEW 인용 / 0 변경)
   - §6 면접 답변 매핑 5 영역 + 꼬리 질문
3. **ADR 0021** 결정 추적 (본 ADR)
4. **AGENTS.md §7** 2 신규 행 (PRINCIPLES 패턴 7→10 / KARPATHY 매칭)

### 시그널 강화 (+)

- **양면 정책 11 ADR 정립**: 0011-**0021** = 본격 시니어 시그널 누적
- **귀납 + 연역 통합**: 본인 영역 14 카드 (귀납) + 카파시 8 본능 (연역)
- **I-1 진입 자료**: 면접 답변 매핑 5 영역 + 꼬리 질문 시뮬레이션
- **매칭 점수 진화 추적**: 76 → 87점 / 진화 사유 본문 명시
- **결정 근거 추적**: 6개월 후 본인 답 가능 (PRINCIPLES 원칙 5)
