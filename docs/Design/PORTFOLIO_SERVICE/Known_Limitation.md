## 데이터 한계

### Survivorship Bias
- **증상:** 현재 S&P 500 구성 종목만 사용 → 과거 탈락 종목 미포함 → 성과 과대평가
- **대응:** 인정 + 문서화, 분석 기간을 6년으로 제한
- **향후:** 시점별 구성 종목 데이터 사용

### yfinance 신뢰성
- **증상:** 무료 API로 간헐적 데이터 누락, Rate limiting
- **대응:** 일괄 다운로드 방식, 결측 5% 초과 종목 제거 (482/503)
- **향후:** 유료 데이터 제공사 사용

## 모델 한계

### 정규분포 가정
- **증상:** 실제 수익률은 Fat tail (482/482 종목 정규분포 기각)
- **대응:** VaR + 몬테카를로로 보완, t-분포 적용 고려
- **수치:** 평균 초과첨도 13.1, GL 종목 -45.8% 편차 (정규분포 예측 대비 8배)

### 정적 공분산
- **증상:** 위기 시 상관관계 급등 (COVID: 0.25→0.61), 분산 효과 약화
- **대응:** Shrinkage로 안정화 (조건수 91% 개선)
- **향후:** 롤링 윈도우 공분산, EWMA, DCC-GARCH

### 거래비용 단순화
- **증상:** 고정 0.1% 적용, 실제는 종목/규모별 상이
- **대응:** 인식 + 문서화
- **향후:** 시장 충격(market impact) 모델 추가
