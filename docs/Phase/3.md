# Phase 3: auth-service 구현

> **상태: ✅ 완료**

## 완료 요약

| 항목 | 계획 | 실제 |
|------|------|------|
| 인증 | JWT + Redis | JWT + Redis + **블랙리스트** + **Reuse Detection** |
| Rate Limiting | - | **Redis sliding window (IP당 분당 10회)** 추가 |
| DB 마이그레이션 | - | **Flyway** 추가 (ddl-auto: validate) |
| 보안 헤더 | - | **HSTS + CSP** 추가 |
| 비밀번호 | @Size(min=8) | **@Pattern (대/소문자+숫자+특수문자)** 강화 |
| 테스트 | 3개 파일 | **8개 파일, 70개 테스트** |
| 코드 리뷰 | - | **19건 수정 (Critical 6 + Major 7 + Minor 6)** |

## 계획 대비 변경점

### Critical 보안 수정 6건
1. **JWT Secret 하드코딩 제거**: 환경변수화 + 32바이트 미만 거부
2. **DB 비밀번호 하드코딩 제거**: 환경변수화 + `.env.example` 생성
3. **Bearer Token 파싱 안전화**: `resolveToken()` + `startsWith` 검증
4. **Rate Limiting 추가**: Redis sliding window + 429 + Retry-After
5. **Refresh Token Reuse Detection**: jti 기반 탈취 감지 → 전체 세션 무효화
6. **Access Token 블랙리스트**: 로그아웃 시 즉시 무효화 (TTL = 잔여 만료시간)

### 추가된 기능
- **RateLimitInterceptor**: `/api/auth/login`, `/api/auth/signup`에 적용
- **CustomAuthenticationEntryPoint**: 401 응답을 ApiResponse JSON으로 통일
- **MdcLoggingFilter**: requestId(UUID) + clientIp 추적
- **JpaAuditingConfig**: `@EnableJpaAuditing` 분리 (테스트 안정성)
- **Flyway**: `V1__init.sql` 마이그레이션 (ddl-auto: update → validate)
- **보안 헤더**: HSTS (1년) + CSP (`default-src 'self'`)
- **구조화 로깅**: logstash-logback-encoder (JSON 포맷)
- **장애 시뮬레이션 테스트**: 8개 (Redis 3 + DB 2 + JWT 3)

### 버전 변경
- Spring Boot: `3.2.2` → **`3.2.12`** (보안 패치)
- JJWT: `0.12.3` → **`0.12.5`**
- Flyway: 추가 (`9.22.3`)
- logstash-logback-encoder: 추가 (`7.4`)
