## 계획 대비 변경점

### 포트 충돌 수정
- PostgreSQL: `5432` → **`5433:5432`** (로컬 PostgreSQL과 충돌 방지)
- Redis: `6379` → **`6380:6379`** (로컬 Redis와 충돌 방지)

### 8개 런타임 이슈 발견 및 수정

| # | 이슈 | 원인 | 수정 |
|---|------|------|------|
| 1 | ENV 변수명 불일치 | docker-compose: `GEMINI_API_KEY` vs llm-service: `GOOGLE_API_KEY` | 변수명 통일 |
| 2 | 포트 충돌 | 로컬 PostgreSQL과 5432 충돌 | 5433으로 변경 |
| 3 | prometheus_client 누락 | requirements.txt에 미포함 | 추가 |
| 4 | yfinance 429 | 구버전 재시도 미처리 | >=0.2.40 업그레이드 |
| 5 | yfinance 1.x Breaking Change | DataFrame 반환 형태 변경 | isinstance 체크 추가 |
| 6 | 임베딩 모델 Deprecation | embedding-001 → 404 | gemini-embedding-001 변경 |
| 7 | ChromaDB 벡터 차원 불일치 | 768 vs 3072 | DB 재생성 |
| 8 | async/middleware 충돌 | 이벤트 루프 블로킹 + body 소비 | async→def + 미들웨어 수정 |

### 추가된 기능
- **Health check**: 모든 서비스에 `/health` 엔드포인트 + Docker HEALTHCHECK
- **depends_on**: 서비스 시작 순서 보장 (postgres → redis → auth → portfolio → llm → frontend)
- **볼륨 3개**: postgres_data, redis_data, llm_chroma_data (데이터 영속성)
- **환경변수 통합**: `.env` 파일 하나로 전체 서비스 설정
