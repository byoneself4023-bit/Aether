## 계획 대비 변경점

### 임베딩 모델 변경
- 계획: `embedding-001`
- 실제: `gemini-embedding-001` (기존 모델 Deprecation으로 404 에러 → 마이그레이션)
- ChromaDB 벡터 차원: 768 → **3072** (DB 재생성)

### 추가된 기능
- **프롬프트 인젝션 방어**: `guardrails.py` (입력 검증, 위험 패턴 탐지)
- **Hallucination 검증**: `validators.py` (수치 범위 확인, 출처 검증)
- **토큰 사용량/비용 추적**: `token_tracker.py` + `/api/metrics` 엔드포인트
- **LLM Provider 추상화**: `llm_provider.py` (Gemini 외 다른 모델 교체 가능)
- **프롬프트 버전 관리**: `prompt_registry.py` (템플릿 버전별 관리)
- **RAG 품질 평가**: `rag_evaluator.py` (검색 정확도 측정)
- **Rate Limiting**: `middleware/rate_limit.py`
- **LLM 응답 캐시**: `cache.py`
- **구조화 로깅**: `middleware/logging.py`
