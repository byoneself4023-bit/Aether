## 계획 대비 변경점

### 프레임워크 메이저 업그레이드
- Next.js `14` → `16` (App Router 강화, React 19 지원)
- React `18` → `19` (Server Components, use() hook)
- Zustand `4` → `5` (API 변경: `create()` → `createStore()`)
- Tailwind `3` → `v4` (CSS-first config, PostCSS 플러그인 변경)
- Recharts `2.10` → `3.7` (React 19 호환)

### Critical 보안 수정 4건
1. **Access Token 메모리 분리**: localStorage → Zustand 메모리 (XSS 방어)
2. **Refresh Token만 localStorage**: 탈취되어도 Access Token 재발급 필요
3. **Route Guard 추가**: 미인증 사용자 대시보드 접근 차단
4. **API 인터셉터 팩토리 패턴**: 401 감지 → 자동 토큰 갱신 → 원래 요청 재시도

### 추가된 기능
- **`partialize`**: Zustand persist에서 민감 정보 제외 (XSS 방어)
- **`_hasHydrated`**: SSR hydration mismatch 방지 패턴
- **전체 한국어화**: UI 텍스트, 에러 메시지
- **접근성**: aria-label, htmlFor/id, color-scheme
- **데모 라벨**: 데모 환경 표시
