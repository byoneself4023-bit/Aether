# Phase 1: portfolio-service 구현

> **상태: ✅ 완료**

## 완료 요약

| 항목 | 계획 | 실제 |
|------|------|------|
| 최적화 | Markowitz MVP + MSR | MVP + MSR + 효율적 프론티어 + 진단 정보 |
| 리스크 | VaR + 몬테카를로 | Parametric VaR + MC VaR + CVaR |
| 백테스트 | Walk-forward | Walk-forward + 거래비용 + 성과 메트릭 |
| 테스트 | test_optimizer, test_risk, test_backtest | **10개 모듈, 212개 테스트** |
| 코드 리뷰 | - | **11건 수정 (Critical 4 + Major 4 + Minor 3)** |

## 계획 대비 변경점

### 추가된 기능
- **공분산 행렬 검증 + 자동 정칙화**: `validate_covariance_matrix()` + `regularize_covariance()`
- **Ledoit-Wolf Shrinkage 자동 적용**: `shrinkage_covariance()` (scikit-learn)
- **부분 실패 허용**: `fetch_prices_resilient()` — 일부 티커 실패 시 나머지로 계속
- **드리프트 탐지**: 최근 20일 vs 과거 데이터 비교 (변동성/상관관계 급변 감지)
- **비중 변화 모니터링**: 이전 비중 대비 변화 알림
- **Prometheus 메트릭**: 최적화 요청 수, 지연 시간, 조건수 히스토그램
- **MLflow 실험 라우터**: `/api/experiments` 엔드포인트 추가
- **장애 시뮬레이션 테스트**: 6개 (외부 API 장애 3 + 수치 안정성 3)

### 버전 변경
- yfinance: `0.2.33` → `>=0.2.40` (1.x API Breaking Change 대응)
- prometheus-client: 추가 (`0.19.0`)
- httpx: 추가 (`0.25.2`)
- pydantic-settings: 추가 (`2.1.0`)
